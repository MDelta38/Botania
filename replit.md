# Botania Mod — Decompiled Source

Botania is a Minecraft Forge mod (version r1.8-249 for Minecraft 1.7.10) by Vazkii that adds nature magic to the game.

## Project contents

| Directory | Description |
|-----------|-------------|
| `botania/` | Original compiled `.class` files + mod assets (sounds, textures, lang files) |
| `decompiled/` | Decompiled Java source output (929 `.java` files), produced by CFR 0.152 |

The `decompiled/vazkii/botania/` tree mirrors the original package structure:
- `api/` — Public API classes (BotaniaAPI, brews, corporea, etc.)
- `client/` — Rendering and client-side logic
- `common/` — Shared mod logic (blocks, items, entities, network, world gen)

## How the decompilation was done

```bash
# Install Java
# Pack class files into a JAR
jar cf botania.jar -C botania .
# Decompile with CFR
java -jar cfr-0.152.jar botania.jar --outputdir decompiled
```

## Notes

- This is **decompiled** bytecode — variable names may be obfuscated or auto-generated by CFR.
- The original Forge/MCP mappings are not applied, so Minecraft internals may show as `func_XXXXX` / `field_XXXXX` names.
- No build system is present; this project is for reading/studying, not compiling.
